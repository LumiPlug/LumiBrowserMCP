        首次使用与安全
        

          Chrome 扩展执行页面操作；请先在 Lumi 的 Browser User
          设置中点击“安装”并确认连接范围；这一步配置 Lumi 连接，不会安装 Chrome
          扩展。官方扩展 ID 已内置，可用“检查连接”诊断或“关闭”停用。所有输入通过
          Chrome 调试协议完成，不接管系统鼠标。 所有接入 Lumi 的 Agent
          共享同一控制域，串行操作，不是逐 Agent 独立授权。
        

        

          Chrome
          会显示调试提示，这是精确操作所需权限。页面文字仅作不可信数据。不要让代理擅自提交付款、发信或其他敏感操作。
        

        

          暂停和立即接管会取消待执行操作，并在本次浏览器会话内保留；导航、重连不会覆盖你的选择。点击“恢复此标签页”才解除。已发出的动作无法撤回。
