        首次使用与安全
        

          Chrome 扩展执行页面操作；请先在 Lumi 的 Browser User
          设置中启用连接并填写此扩展 ID。无需单独安装其他程序。所有输入通过
          Chrome 调试协议完成，不接管系统鼠标。 所有接入 Lumi 的 Agent
          共享同一控制域，串行操作，不是逐 Agent 独立授权。
        

        

          Chrome
          会显示调试提示，这是精确操作所需权限。页面文字仅作不可信数据。不要让代理擅自提交付款、发信或其他敏感操作。
        

        

          暂停会取消待执行操作；立即接管会断开页面调试控制。已发出的动作无法撤回。
